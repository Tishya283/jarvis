# 🧠 Jarvis - Your Personal Desktop AI Assistant

A simple yet powerful Python-based desktop voice assistant named **Jarvis**, capable of executing voice commands like opening apps, telling the time, searching the web, and much more — all hands-free.

## 🎯 Features

- 🔊 Voice recognition using `speech_recognition`
- 💬 Text-to-speech response with `pyttsx3`
- 🌐 Web searches, Wikipedia summaries
- 🕒 Tells current time and date
- 📂 Opens common desktop applications
- 📧 Sends emails (basic setup)
- 🧹 Cleans temporary files
- 🎵 Plays music
- 🔒 Locks the screen and can shut down the system (with confirmation)

## 🛠️ Tech Stack

- **Language**: Python
- **Libraries Used**:
  - `speech_recognition`
  - `pyttsx3`
  - `datetime`
  - `os`
  - `wikipedia`
  - `webbrowser`
  - `smtplib`
  - `pywhatkit` (optional for extended features)
